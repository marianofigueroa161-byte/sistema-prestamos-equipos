# Sistema Web de Préstamos de Equipos Tecnológicos

Aplicación web desarrollada para registrar y controlar el préstamo de laptops, proyectores, tablets, monitores y otros equipos tecnológicos.

## Func:** Funcionalidades

- Registro de equipos tecnológicos.
- Control del responsable y de las fechas de préstamo y devolución.
- Estados: Disponible, PrestadoOhPrestado y Mantenimiento.
- Identificación automática de préstamos vencidos.
- Edición y eliminación de registros.
- Búsqueda por código, equipo o responsable.
- Filtrado por estado.
- Resumen estadístico.
- Persistencia de información mediante Local Storage.
- Diseño adaptable a computadoras y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES6
- Local Storage API
- Git
- GitHub
- Visual Studio Code

## Ejecución

1. Descargue y descomprima el proyecto.
2. Abra la carpeta en Visual Studio Code.
3. Abra el archivo `index.html` con un navegador o con la extensión Live Server.

No se requiere instalar dependencias adicionales.
